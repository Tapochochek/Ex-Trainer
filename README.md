# Тренажёр к экзамену

Один файл `index.html`, без зависимостей. Работает на телефоне, планшете и ПК.

## Публикация на GitHub Pages
Settings -> Pages -> Deploy from a branch -> main / (root). Ссылка вида `https://<логин>.github.io/<репозиторий>/`.

## Вопросы
Лежат в массиве `QS` внутри `index.html` (761 вопрос, 14 разделов).
Поля: `s` - номер раздела (0..13), `n` - номер вопроса, `q` - текст, `o` - варианты, `a` - индекс верного (с 0).
Новые вопросы добавляйте только в конец массива: прогресс и избранное хранятся по позиции вопроса.
Варианты тасуются, кроме вопросов, где есть ссылки вроде "варианты 1 и 2" или "верны все варианты".

## Прогресс
Хранится в localStorage браузера (отдельно на каждом устройстве).

## Клавиши на ПК
1-9 - выбрать вариант, стрелки влево/вправо - предыдущий/следующий вопрос, Esc - выход.
